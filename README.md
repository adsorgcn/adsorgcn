### What I Build

**AI-native tools and open data** — products that are built by AI, written by AI, and designed for both humans and machines.

### Active Projects

🏨 **[Hotel Corporate Codes](https://hotelcorporatecodes.com)** — The largest database of hotel corporate discount codes (Marriott, Hilton, IHG, Hyatt & more). AI Travel Advisor recommends the best code for your destination. Every consultation generates a unique travel guide page.
- [`hotel-corporate-codes`](https://github.com/adsorgcn/hotel-corporate-codes) — Open-source codes database, 123+ verified codes, available as npm package.

🏠 **[Real Address Generator](https://realaddressgenerator.online)** — Generate real, formatted addresses for 22+ countries. Used for testing, development, and form validation.

📡 **[I-Lang Protocol](https://ilang.ai)** — An AI-native communication protocol for structured data exchange between humans and AI systems. Three-layer architecture: PUBLIC / PRIVATE / SOUL.
- Chinese site: [ilang.cn](https://ilang.cn)
